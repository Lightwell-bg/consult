# Quick Start Guide — AI-консультант отдела продаж

Краткая инструкция: куда заходить в Telegram, какие команды вводить и какие кнопки нажимать.

> Бот работает **только в личных сообщениях** (не в группах). Доступ — по белому списку: если вас ещё не добавили, бот ответит «У вас нет доступа».

---

## Как открыть бота

1. Откройте Telegram.
2. Найдите бота по имени (его выдаёт администратор при подключении).
3. Нажмите **Запустить** / отправьте `/start`.
4. Меню команд — кнопка **☰** (или поле ввода `/`) слева от строки сообщения.

---

# Раздел для сотрудников

Вы — обычный пользователь, если в меню команд **нет** `/reload`, `/config`, `/logs`.

## Первый вход

| Шаг | Что делать | Что увидите |
|-----|------------|-------------|
| 1 | Отправьте `/start` | Приветствие и краткая справка |
| 2 | Отправьте `/whoami` | Ваш Telegram ID — передайте администратору, если доступа ещё нет |
| 3 | Дождитесь добавления в белый список | Админ добавит вас через `/config` → **👥 Пользователи** |
| 4 | Снова `/start` | Можно задавать вопросы |

## Как задать вопрос

**Ничего нажимать не нужно** — просто напишите текст в чат, без команды.

Примеры:

```
Сколько стоит арабика 1 кг?
Что отвечать, если клиент говорит «дорого»?
Кто отвечает за поставки?
Какие условия для оптовиков?
```

Бот ищет ответ в базе знаний компании и отвечает структурированным текстом (заголовки, списки, цитаты для клиента).

### Если данных нет

Бот честно напишет, что в базе знаний нет информации, и подскажет, к кому обратиться (если такие контакты есть в БЗ).

### Уточняющие вопросы

Бот помнит последние сообщения диалога. Можно писать коротко:

```
А для офиса?
А если клиент сравнивает с конкурентом?
```

## Команды сотрудника

Откройте меню **☰** или введите команду вручную:

| Команда | Когда использовать |
|---------|-------------------|
| `/start` | Первый запуск, напоминание как пользоваться |
| `/help` | Справка с примерами вопросов |
| `/whoami` | Узнать свой Telegram ID (работает даже без доступа) |
| `/status` | Проверить, загружена ли база знаний и когда обновлялась |

### `/status` — что смотреть

- **База знаний: ✅ загружена** — бот готов отвечать.
- **Записей в базе** — сколько строк загружено из таблицы.
- **Последняя синхронизация** — когда данные обновлялись.

## Что нельзя / не нужно

- Не нужны кнопки — только текстовые вопросы.
- Команды `/reload`, `/config`, `/logs` — **только для админов**; сотруднику придёт «доступно только администраторам».
- Не пересылайте боту голосовые и файлы как вопрос — бот отвечает на **текст**.

# Раздел для администраторов

Вы — администратор, если в меню команд есть `/reload`, `/config`, `/logs`.

## Быстрый старт админа

| Шаг | Действие |
|-----|----------|
| 1 | `/start` — обновить меню команд |
| 2 | `/config` — открыть админ-панель |
| 3 | **👥 Пользователи** → **➕ Добавить пользователя** — выдать доступ сотрудникам |
| 4 | `/reload` — загрузить базу знаний из Google Таблицы |
| 5 | `/status` — убедиться, что БЗ загружена |

## Все команды администратора

| Команда | Назначение |
|---------|------------|
| `/start` | Приветствие + обновление меню |
| `/help` | Справка для сотрудников |
| `/whoami` | Ваш Telegram ID |
| `/status` | Состояние бота и БЗ |
| `/reload` | Принудительно обновить базу знаний |
| `/config` | Настройки, пользователи, синхронизация |
| `/logs` | Журнал критических ошибок |
| `/cancel` | Отменить ввод, если бот ждёт текст (настройка, добавление пользователя) |

## `/config` — админ-панель

Отправьте `/config`. Появится сообщение **⚙️ Админ-панель** с кнопками:

```
👥 Пользователи
🔗 ID таблицы Google
🔄 Режим синхронизации
⏱ Интервал синхронизации (мин)
💬 Контекст (макс. сообщений)
📋 Текущие настройки
🗂 Хранение логов (дней)
```

Нажимайте нужную кнопку — бот либо покажет меню, либо попросит ввести значение текстом.

### 👥 Пользователи — белый список

**Открыть:** `/config` → **👥 Пользователи**

На экране — список всех, у кого есть доступ:

- 👤 — сотрудник  
- 👑 — администратор  

**Кнопки внизу:**

| Кнопка | Действие |
|--------|----------|
| Имя в списке | Открыть карточку пользователя |
| ◀️ / ▶️ | Листать страницы (если пользователей много) |
| ➕ Добавить пользователя | Мастер добавления |
| ← Назад в настройки | Вернуться в `/config` |

#### Добавить нового сотрудника

1. **➕ Добавить пользователя**
2. Сотрудник присылает вам свой ID: `/whoami` → число вида `449466944`
3. Введите этот **Telegram ID** и отправьте сообщением
4. Введите **имя** (например, `Иван Петров`)
5. Нажмите **👤 Сотрудник** или **👑 Администратор**
6. Готово — сотрудник может писать боту вопросы

#### Карточка пользователя

Нажмите на имя в списке. Доступные кнопки:

| Кнопка | Действие |
|--------|----------|
| ✏️ Изменить имя | Ввести новое имя текстом |
| 👑 Сделать администратором | Выдать права админа (+ команды `/reload`, `/config`, `/logs`) |
| 👤 Убрать права админа | Оставить только доступ сотрудника |
| 🗑 Удалить пользователя | Убрать из белого списка |
| ← К списку | Назад к списку |

> Нельзя удалить себя и нельзя убрать/удалить **последнего** администратора.

---

### 🔗 ID таблицы Google

**Открыть:** `/config` → **🔗 ID таблицы Google**

1. Бот попросит ввести ID таблицы с базой знаний.
2. Скопируйте ID из URL Google Таблицы / Диска:  
   `https://docs.google.com/spreadsheets/d/ВОТ_ЭТОТ_ID/edit`
3. Вставьте ID одним сообщением.
4. Отмена: `/cancel`

---

### 🔄 Режим синхронизации

**Открыть:** `/config` → **🔄 Режим синхронизации**

Выберите один из вариантов:

| Кнопка | Когда использовать |
|--------|-------------------|
| **При каждом запросе** | БЗ обновляется перед каждым ответом (медленнее, но всегда свежо) |
| **По расписанию** | Автообновление каждые N минут (рекомендуется) |
| **Вручную (/reload)** | Обновление только по команде `/reload` |
| **← Назад** | В админ-панель |

---

### ⏱ Интервал синхронизации (мин)

**Открыть:** `/config` → **⏱ Интервал синхронизации (мин)**

- Работает при режиме **По расписанию**.
- Введите число, например `10` (каждые 10 минут).
- Отмена: `/cancel`

---

### 💬 Контекст (макс. сообщений)

**Открыть:** `/config` → **💬 Контекст (макс. сообщений)**

- Сколько последних реплик диалога помнит бот (по умолчанию 10).
- Минимум: 2.
- Введите число, например `10`.
- Отмена: `/cancel`

---

### 📋 Текущие настройки

**Открыть:** `/config` → **📋 Текущие настройки**

Показывает все параметры без изменений:

- ID таблицы  
- Режим и интервал синхронизации  
- Размер контекста  
- Top-K поиска  
- Срок хранения логов  

---

### 🗂 Хранение логов (дней)

**Открыть:** `/config` → **🗂 Хранение логов (дней)**

- Срок хранения критических ошибок в базе бота (по умолчанию 30 дней).
- Введите число, например `30`.
- Старые записи удаляются автоматически.
- Отмена: `/cancel`

---

## `/reload` — обновить базу знаний

Когда правите Google Таблицу с ответами:

1. Сохраните изменения в таблице.
2. Подождите **10–30 секунд** (если файл — Excel на Google Диске).
3. Отправьте `/reload`.

Ответ бота:

```
⏳ Обновляю базу знаний...
✅ База знаний обновлена. Загружено записей: 155
Изменение: +1 (было 154)
📄 Файл на Drive: 2026-06-09T16:37:00.000Z
```

**На что смотреть:**

- Число записей выросло после добавления строки.
- Строка **Изменение** показывает разницу с прошлым `/reload`.
- **Дата файла на Drive** — файл действительно обновился.

> При режиме **Вручную** сотрудники не получают новые ответы, пока админ не сделает `/reload`.

## Уведомления о «дырах» в базе знаний

Когда вопрос **не находит уверенного совпадения в БЗ**, всем **администраторам** (включая вас, если тестируете сами) приходит личное сообщение:

```
⚠️ Ответ в базе знаний не найден

Вопрос:
<текст вопроса сотрудника>

Спросил: Иван Петров (ID 123456789)
```

Используйте это, чтобы дополнять таблицу новыми ответами. Сотрудник при этом получает обычный ответ бота («данных нет»).

В логах бота при срабатывании появятся строки `KB miss:` и `KB miss alert sent to admin …`. Если уведомлений нет — проверьте, что ваш Telegram ID в списке с `is_admin=1` (`/config` → Пользователи).

---

## `/logs` — журнал ошибок

Отправьте `/logs` — последние критические сбои:

- ошибки синхронизации БЗ;
- сбои Anthropic API;
- проблемы при `/reload`.

Используйте для диагностики, если бот «молчит» или не обновляет таблицу.

---

## Работа с базой знаний (для админа)

Таблица на Google Диске / Google Sheets. Столбцы:

| Раздел | Вопрос | Ответ |
|--------|--------|-------|
| 23. Возражения и экономика | Что отвечать на «дорого»? | Текст ответа… |

**Важно:**

- Строка **без ответа** в столбце «Ответ» **не загружается**.
- Данные должны быть в правильных столбцах: Раздел → Вопрос → Ответ.
- После правок — `/reload` (или дождитесь авто-синхронизации).

Подробнее о подключении таблицы и Service Account — в [README.md](README.md).

## Типичные сценарии

### Новый сотрудник в команде

1. Сотрудник: `/whoami` → отправляет ID админу  
2. Админ: `/config` → **👥 Пользователи** → **➕ Добавить** → ID → имя → **👤 Сотрудник**  
3. Сотрудник: `/start` → задаёт вопрос текстом  

### Добавили строку в таблицу, бот не видит

1. Проверьте, что заполнен столбец **Ответ**  
2. Подождите 10–30 сек, `/reload`  
3. `/status` — число записей выросло?  
4. Задайте вопрос, как в таблице (можно своими словами)  

### Сменили таблицу на другую

1. `/config` → **🔗 ID таблицы Google** → новый ID  
2. `/reload`  
3. `/status` — проверить загрузку  

### Бот отвечает «нет доступа»

- Пользователя нет в белом списке → админ добавляет через **👥 Пользователи**  
- Или сотрудник пишет не с того Telegram-аккаунта → сверить ID через `/whoami`

## Шпаргалка

| Роль | Главное действие |
|------|------------------|
| **Сотрудник** | Написать вопрос текстом |
| **Админ** | `/config` → пользователи и настройки; `/reload` → обновить БЗ |

| Проблема | Команда |
|----------|---------|
| Нет доступа | `/whoami` → админу → добавить в **👥 Пользователи** |
| Старые ответы | `/reload` |
| Бот сломался | `/logs` + `/status` |
