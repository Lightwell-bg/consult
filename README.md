# TG Sales AI Bot

Внутренний AI-консультант отдела продаж на базе Telegram + Anthropic Claude.

Бот отвечает на вопросы сотрудников по продукту, ценам, условиям работы и скриптам продаж, используя базу знаний из Google Таблицы. Доступ — по белому списку Telegram ID. Все настройки хранятся в SQLite и управляются командой `/config` в боте.

**Инструкция для пользователей и админов:** [QuickStartGuide.md](QuickStartGuide.md)

---

## Стек

| Компонент | Технология |
|-----------|-----------|
| Bot framework | aiogram 3.x + asyncio |
| AI | Anthropic Claude (claude-sonnet-4) |
| База знаний | Google Sheets API (Service Account) |
| Хранилище | SQLite (aiosqlite) |
| Планировщик | APScheduler |
| Деплой | Docker + docker-compose |

## Быстрый старт (локально)

### 1. Клонировать и создать виртуальное окружение

```bash
git clone <repo-url>
cd consult
python -m venv .venv
source .venv/Scripts/activate   # Windows (Git Bash / WSL)
# или
source .venv/bin/activate        # Linux / macOS
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Настроить переменные окружения

Скопируйте `.env.example` в `.env` и заполните:

```bash
cp .env.example .env
```

```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
ANTHROPIC_API_KEY=ваш_api_ключ_Anthropic
ANTHROPIC_MODEL=claude-sonnet-4-6
GOOGLE_SERVICE_ACCOUNT_FILE=credentials/google-service-account.json
DATABASE_PATH=data/bot.db
LOG_LEVEL=INFO
```

### 4. Настроить Google Service Account

1. Откройте [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте новый проект или выберите существующий.
3. Включите API в Google Cloud Console (API и сервисы → Библиотека):
   - **Google Sheets API**
   - **Google Drive API** (нужен, если база знаний — Excel-файл на Диске)
4. Создайте Service Account: IAM и администрирование → Сервисные аккаунты → Создать.
5. Скачайте JSON-ключ (см. подробную инструкцию ниже).
6. **Важно:** расшарьте вашу Google Таблицу на email сервисного аккаунта с правами «Читатель».
   Email аккаунта указан на странице сервисного аккаунта и выглядит как `имя@project-id.iam.gserviceaccount.com`.

#### Как скачать JSON-ключ

После создания сервисного аккаунта вы попадёте на страницу его деталей (вкладка **Details**). JSON-ключ скачивается **не здесь**, а на соседней вкладке:

1. На странице сервисного аккаунта откройте вкладку **Keys** (между **Permissions** и **Metrics**).
2. Нажмите **Add key** → **Create new key**.
3. Выберите тип **JSON**.
4. Нажмите **Create** — файл автоматически скачается в браузер.

#### Куда положить файл в проекте

```bash
mkdir -p credentials
```

1. Переименуйте скачанный файл (обычно `project-id-xxxxx.json`) в `google-service-account.json`.
2. Переместите его в папку `credentials/`:

```
consult/
└── credentials/
    └── google-service-account.json
```

3. Убедитесь, что в `.env` указан правильный путь:

```env
GOOGLE_SERVICE_ACCOUNT_FILE=credentials/google-service-account.json
```

> **Важно:** файл `credentials/` добавлен в `.gitignore` — никогда не коммитьте JSON-ключ в git.

#### Дать доступ к Google Таблице

1. Откройте вашу Google Таблицу с базой знаний.
2. Нажмите **Настройки доступа** (кнопка «Поделиться»).
3. Добавьте email сервисного аккаунта (например, `kwork260609@n8n-proj-484212.iam.gserviceaccount.com`) с правами **Читатель**.
4. Сохраните.

Без этого шага бот не сможет читать таблицу, даже при корректном JSON-ключе.

> Если на вкладке **Keys** нет кнопки **Add key**, возможно, в организации запрещено создание ключей — обратитесь к администратору Google Cloud.

### 5. Создать папку данных и добавить первого администратора

```bash
mkdir -p data credentials

# Добавить администратора (замените ID на ваш Telegram ID)
# Узнать свой ID можно у бота @userinfobot
python scripts/seed_admin.py 123456789 --admin --name "Ваше Имя"
```

### 6. Запустить бота

```bash
python -m src.main
```

## Команды бота

### Для всех пользователей (белый список)

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и краткая инструкция |
| `/help` | Полная справка по использованию |
| `/whoami` | Показать ваш Telegram ID (работает без авторизации) |
| `/status` | Состояние бота, статус синхронизации БЗ |

### Только для администраторов

| Команда | Описание |
|---------|----------|
| `/reload` | Принудительное обновление базы знаний из Google Таблицы (показывает изменение числа записей и дату файла на Drive) |
| `/config` | Открыть меню настроек (ID таблицы, режим синхронизации и др.) |
| `/logs` | Журнал критических ошибок (из SQLite) |

При вопросе сотрудника без совпадения в БЗ всем администраторам приходит личное уведомление с текстом вопроса (см. [QuickStartGuide.md](QuickStartGuide.md)).

## Настройки через `/config`

Все настройки хранятся в SQLite (`settings` таблица) и управляются администратором прямо в боте:

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `spreadsheet_id` | `15wtvU9GVkfNaCC3tMmAjJBqfmxtXQu7S` | ID Google Таблицы с БЗ |
| `sync_mode` | `scheduled` | `on_request` / `scheduled` / `manual` |
| `sync_interval_minutes` | `10` | Интервал в минутах для `scheduled` режима |
| `max_context_messages` | `10` | Сколько последних сообщений помнит бот |
| `search_top_k` | `8` | Сколько фрагментов БЗ передавать в AI |
| `log_retention_days` | `30` | Срок хранения критических логов в SQLite (дней) |

### Журнал критических ошибок

В SQLite (`logs`) сохраняются только **критические** сбои:
- ошибки синхронизации базы знаний;
- сбои Anthropic API;
- невозможность загрузить БЗ при обращении пользователя.

Просмотр: команда `/logs` (только администратор).

Срок хранения настраивается в `/config` → **🗂 Хранение логов (дней)**. Записи старше N дней удаляются автоматически при старте бота и при каждой новой записи.

Обычные события (старт бота, обработка сообщений) по-прежнему пишутся только в консоль (`LOG_LEVEL` в `.env`).

### Меню команд в Telegram

При старте бот регистрирует меню команд (`/` в поле ввода):

| Роль | Команды |
|------|---------|
| Сотрудник | `/start`, `/help`, `/whoami`, `/status` |
| Администратор | + `/reload`, `/config`, `/logs` |

Меню обновляется при `/start`, при назначении/снятии админа и при добавлении пользователя. Это только подсказки — доступ по-прежнему проверяется в коде.

## Структура базы знаний (Google Таблица)

Первый лист таблицы должен содержать три колонки (заголовки автоматически распознаются):

| Раздел | Вопрос / тема | Ответ / информация |
|--------|--------------|-------------------|
| 15. Классификация кофе | Чем арабика отличается от робусты? | Арабика — мягкий вкус... |
| 23. Возражения | Клиент говорит «дорого» | Сравните с ценой порции... |
| Контакты | Ответственный за поставки | Иван Петров, ivan@company.ru |

Бот поддерживает гибкое сопоставление заголовков — подойдут варианты на русском и английском.

## Системные промпты

Файлы в папке `prompts/` управляют поведением AI:

- `prompts/system.md` — основная инструкция: отвечать только по БЗ, стиль «коллега из продаж», правила форматирования для Telegram (заголовки, списки, эмодзи).
- `prompts/fallback.md` — используется, когда в БЗ нет подходящего ответа.

Ответы бота автоматически конвертируются из markdown в Telegram HTML (жирный текст, списки, цитаты). Редактируйте промпты под свой контекст и перезапустите бота.

## Управление пользователями

### Первый администратор (только при первом запуске)

Скрипт нужен один раз — чтобы добавить себя в систему до того, как появится доступ к `/config`:

```bash
python scripts/seed_admin.py 123456789 --admin --name "Ваше Имя"
```

Узнать свой Telegram ID: команда `/whoami` в боте (работает без авторизации).

### Дальше — через админ-панель в боте

Все остальные операции с пользователями выполняются администратором в Telegram:

1. `/config` → **👥 Пользователи**
2. Доступные действия:
   - **➕ Добавить** — ввести Telegram ID → имя → выбрать роль (сотрудник / администратор)
   - **Нажать на пользователя** — открыть карточку
   - **✏️ Изменить имя** — редактировать отображаемое имя
   - **👑 Сделать администратором** / **👤 Убрать права админа**
   - **🗑 Удалить** — убрать из белого списка

В списке отображается **имя и Telegram ID** (например: `Иван Петров (449466944)`).

Ограничения:
- нельзя удалить самого себя;
- нельзя удалить или разжаловать последнего администратора.

## Troubleshooting

### `Conflict: can't use getUpdates method while webhook is active`

У бота был настроен webhook (например, на другом сервере или через сторонний сервис). Бот при старте автоматически снимает webhook. Перезапустите:

```bash
python -m src.main
```

Если ошибка повторяется, снимите webhook вручную (подставьте свой токен):

```bash
curl "https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/deleteWebhook?drop_pending_updates=true"
```

### `This operation is not supported for this document. The document must not be an Office file`

Файл на Google Диске загружен как **Excel (.xlsx)**, а не как нативная Google Таблица. Бот умеет читать такие файлы через Drive API, но нужно:

1. Расшарить файл на email сервисного аккаунта (права **Читатель**).
2. Включить **Google Drive API** в Google Cloud Console (API и сервисы → Библиотека → Google Drive API → Включить).

Альтернатива (рекомендуется): откройте файл в Google Диске → **Файл → Сохранить как Google Таблицу** и укажите новый ID через `/config`.

### `model: claude-sonnet-4-20250514` — 404 Not Found

Модель устарела или недоступна для вашего API-ключа. Обновите в `.env`:

```env
ANTHROPIC_MODEL=claude-sonnet-4-6
```

Актуальный список моделей: [Anthropic Models](https://platform.claude.com/docs/en/about-claude/models/overview).

### Добавил строку в таблицу, но бот не видит / `/reload` показывает старое число записей

1. Убедитесь, что в строке заполнен столбец **Ответ** — строки без ответа пропускаются.
2. После правки в Excel на Google Диске подождите 10–30 секунд и снова выполните `/reload`.
3. Сравните число записей: если после `/reload` пришло «Изменение: +1», строка загружена.
4. В ответе `/reload` смотрите **дату файла на Drive** — она должна совпадать с моментом сохранения.
5. Если число записей не растёт, проверьте структуру столбцов: **Раздел | Вопрос | Ответ** (данные не должны быть сдвинуты влево).

### Бот не отвечает на сообщения

1. Убедитесь, что ваш Telegram ID в белом списке (`/whoami` → попросите админа добавить через `/config` → Пользователи).
2. Проверьте `/status` — база знаний должна быть загружена.
